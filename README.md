# infraops-ai-agent
인프라 문제 해결을 위한 AI 에이전트<br>
AI agent for infrastructure troubleshooting.

## Goal
이 프로젝트는 인프라 엔지니어가 VM, 네트워크, 방화벽 및 문제 해결 작업을 수행하는 것을 지원하는 AI 에이전트를 제공합니다.<br>
This project provides an AI agent that assists infrastructure
engineers with VM, network, firewall and troubleshooting tasks.

## Tech Stack
- Python
- OpenAI API
- RAG
- Tool Calling
- Streamlit
